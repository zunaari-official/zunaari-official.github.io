# 画像の入れ方ガイド

サイトで使う画像は、このフォルダに以下のファイル名で保存します。
**サイトが読み込むのは `.webp` ファイルです。** 同じファイル名の `.webp` で上書きすれば、
HTML/CSSを変更しなくても画像が差し替わります。

## 運用ルール

- 公開用は `.webp`（1枚あたり 200〜400KB 程度が目安）。
- 元の `.png` は容量が大きいため Git管理の対象外です（`.gitignore` で除外）。
  PC上の `images/` 以下にそのまま残り、バックアップは
  `AI制作/zunaari-music-original-png-backup/` フォルダに保管しています。
- 新しい画像を追加するときは、PNGなどの元画像からWebPに変換してから保存してください。

## hero/（トップの背景）

| ファイル名 | 用途 | 推奨サイズ | 向き |
|---|---|---|---|
| `hero-main.webp` | PC表示の背景画像（`css/style.css` で指定） | 1920×1080px 以上 | 横長（16:9） |
| `hero-mobile-v2.webp` | スマートフォン表示（幅768px以下）の背景画像 | 1080×1080px 程度 | 正方形（1:1） |

※ `hero-mobile.png` は旧バージョンで、現在は使用していません。
