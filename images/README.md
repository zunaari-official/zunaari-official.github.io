# 画像の入れ方ガイド

サイトで使う画像は、このフォルダに以下のファイル名で保存します。
**サイトが読み込むのは `.webp` ファイル（OGPのみ `.jpg`）です。**

## 運用ルール

- 公開用は `.webp`（1枚あたり 400KB 以下が目安）。
- 元の `.png` は容量が大きいため Git管理の対象外です（`.gitignore` で除外）。元画像は公開リポジトリの外で保管します。
- キャラクター画像と作品サムネイルは、画面の大きさに合わせて**サイズ違いのファイル**を読み分けています（`index.html` の `srcset`）。
  画像を差し替えるときは、元画像から下表のサイズ違いもすべて作り直してください（Claude Code が担当）。
- ファイル名の大文字・小文字は、`index.html`／`css/style.css` の記述と完全に一致させてください（GitHub Pages は区別します）。
